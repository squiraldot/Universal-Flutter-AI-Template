# UI Design System

- Follow approved designs; ask before inventing a visual direction.
- Define semantic colors, typography, spacing, radii and elevation centrally.
- Use theme-driven components and shared widgets.
- Avoid raw design values scattered through feature screens.
- Support text scaling, touch targets and screen-reader semantics.
- Design loading, empty, error, disabled and success states.
- Check small/large screens and intentional dark theme.

Fill app-specific values in APP_SPEC.md and implement tokens in lib/core/theme/: brand, secondary, surfaces, text contrast, typography, spacing, radii, motion and icon style.
