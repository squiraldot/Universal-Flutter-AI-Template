# Feature Specifications

Create one file per app feature using the [feature specification template](_TEMPLATE.md).

Each feature specification should cover:
- Purpose and user value
- Entry points and user flows
- Acceptance criteria
- Data model and persistence
- Loading, empty, error, and offline states
- Permissions and privacy impact
- Analytics, only when needed and with minimal personal data
- Unit, widget, and integration tests
- Explicit out-of-scope behavior

Keep specifications focused on observable behavior. Do not treat an unapproved
feature idea as implementation authorization.
